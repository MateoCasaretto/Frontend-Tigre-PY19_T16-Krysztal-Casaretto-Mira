# Frontend – Tigre Uruguay

Frontend de la aplicación desarrollada para **Tigre Uruguay**, construido con **React** y **Vite**.

Este proyecto forma parte del **Proyecto Integrador** de la carrera **Analista en Tecnologías de la Información** de la **Universidad ORT Uruguay**, y fue realizado por el grupo **PY19_T16**.

## Cómo correrlo localmente

```bash
npm install
npm run dev
```
